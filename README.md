# PixelCore

PixelCore is a high-performance, low-latency platform enabling multi-threaded rendering engine architectures and GPU-accelerated computations.

The key benefits of using PixelCore include:

- PixelCore is a high-performance, low-latency
- platform enabling multi-threaded rendering engine
- architectures and GPU-accelerated computations

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/PixelCore.git`
2. `cd PixelCore`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
